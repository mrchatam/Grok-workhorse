# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the work.
Harassment, personal attacks, discriminatory language and publishing others' private information are
not acceptable in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour to the maintainer through GitHub (@mrchatam), privately if possible (for
example through a private security advisory marked "Code of Conduct"). Reports are handled
confidentially. Maintainers may remove content and restrict or ban participants who violate this code,
following the enforcement guidelines of the Contributor Covenant.
